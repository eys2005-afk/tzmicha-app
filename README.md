# 🌱 צמיחה — לוז יומי, מעקב מידות וחשבון נפש

אפליקציה אישית לניהול והתקדמות — בעברית, לנייד ולמחשב.
לוז יומי / שבועי / חודשי על הדברים החשובים: **תורה, תפילה, עבודת המידות (כעס),
חינוך הילדים, ומשימות הבית**. עם **טבלת ניקוד** (הצלחות / חלקי / כשלונות, רצפים)
ו**חשבון נפש** יומי, שבועי וחודשי.

מתאים לשני בני הזוג — כל אחד מסמן את המשימות שלו, ויש גם משימות משותפות.

## המסכים

| **📅 היום** | הלוז שלך — כל המשימות (יומי/שבועי/חודשי). סימון ✓ הצלחה · ◑ חלקי · ✗ כשלון |
| **🎯 יעדים** | ניהול התחומים והמשימות — הוספה, עריכה, תדירות, נקודות, שיוך לבן/בת הזוג |

## שימוש מיידי
פותחים את `index.html` בדפדפן (נייד או מחשב). הכול עובד מיד — הנתונים נשמרים במכשיר.
בנייד אפשר "הוסף למסך הבית" כדי שייראה כמו אפליקציה רגילה.

## אירוח אונליין (מומלץ — כדי לפתוח מכל מקום)
האפליקציה היא קבצים סטטיים בלבד, אז אפשר לארח בחינם, למשל ב-**GitHub Pages**:
1. ב-Settings של הריפו → Pages → Branch: בחרו את הענף → שמרו.
2. הכתובת תהיה משהו כמו `https://<user>.github.io/torah-points-app/`.

> אפליקציית הנקודות לילדים נשמרה ב-`torah-points.html` ועדיין עובדת.

## הפעלת התחברות + סנכרון בין מכשירים (Firebase — חינמי)
כברירת מחדל הנתונים נשמרים מקומית בכל מכשיר בנפרד. כדי שאתה ואשתך תתחברו
ותראו את אותם הנתונים מכל מכשיר:
1. צרו פרויקט חינמי ב-<https://console.firebase.google.com>.
2. הוסיפו אפליקציית Web והעתיקו את אובייקט ה-`firebaseConfig`.
3. הדביקו אותו ב-`app.js` במקום `const FIREBASE_CONFIG = null;`.
4. הפעילו Authentication (Email/Password) ו-Firestore.

> אפשר גם פשוט לבקש ממני (Claude) להשלים את חלק הענף — אני אחבר את הקוד
> ואדריך צעד-אחר-צעד מה ללחוץ בקונסול של Firebase.
